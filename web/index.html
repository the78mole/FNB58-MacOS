Browser-Anforderungen

  • Web Bluetooth: Chrome, Edge, Opera auf Desktop / Android. Auf macOS muss Bluetooth aktiviert sein.
  • WebUSB: Chrome, Edge, Opera auf Desktop / Android. Unter Linux ggf. udev-Regeln für VID 0x0716 setzen. Unter Windows wird ggf. WinUSB als Treiber benötigt (z. B. via Zadig).
  • Die Seite muss über HTTPS (oder localhost) ausgeliefert werden. GitHub Pages erfüllt diese Anforderung automatisch.
  • Es werden keinerlei Daten an einen Server übertragen – die Kommunikation findet komplett im Browser statt.
